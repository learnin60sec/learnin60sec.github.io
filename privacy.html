Privacy policy

My YouTube Uploader, the private tool behind Learn in 60 Seconds. Effective 3 October 2026.

Who uses this tool

My YouTube Uploader is used only by the owner of the YouTube channel Learn in 60 Seconds, to manage that one channel. It is not offered to other people.

What it accesses

With the owner's permission through Google sign-in, the tool uses YouTube API Services to:

  • upload the channel's own videos and set their titles, descriptions, tags and thumbnails;
  • create playlists on the channel and add the channel's videos to them;
  • read the channel's own statistics and YouTube Analytics reports (such as views, watch time and subscribers gained).

How data is stored

The sign-in token is kept privately by the owner, on the owner's computer or as an encrypted secret in the owner's private automation account. Reports about the channel's own videos are stored in the owner's private files. Nothing is sold, shared with third parties or used for advertising.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google terms

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions or through Google security settings. After that, the tool can no longer use the channel.

Contact

Questions about this policy can be sent through the contact details on the channel's About page.
